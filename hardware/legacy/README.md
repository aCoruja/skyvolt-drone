# Legado — frame v1 (peça única)

Primeira versão do chassi, gerada como corpo único (330×290mm). Substituída na Rev. 1.2/1.3 do documento por um design modular de 3 peças (`hardware/frame/`) para caber na mesa de impressão de 220×220mm disponível e para usar o motor brushless RS1606 3300KV real em vez do motor de escova original.

Mantida aqui só como referência histórica — não é a versão a imprimir.
