## Como atualizar

1. Assim que a devolutiva (nota/feedback) sair, editar o arquivo da entrega correspondente com: nota, feedback literal do professor (quando houver), pontos fortes, pontos a corrigir e o commit/tag que foi de fato entregue.
2. Atualizar a linha correspondente na tabela acima (nota + status: `aguardando` → `avaliado`).
3. Não esperar a entrega seguinte para registrar — o valor deste histórico é acompanhar a evolução, não só arquivar o resultado final.
